# Jazz solo MIDI studies

`wjazzd/` contains the unquantized solo MIDI release from the Weimar Jazz Database (WJazzD) v2.1, created by the Jazzomat Research Project at the University of Music FRANZ LISZT Weimar. Keyer pairs each playable transcription with the release's beat-level harmony annotations via `wjazzd-solo-catalog.js`.

Source: <https://jazzomat.hfm-weimar.de/download/download.html>

The WJazzD database is released under the Open Database License (ODbL) 1.0, with its individual contents under the Database Contents License. See <https://opendatacommons.org/licenses/odbl/1.0/>.

The source MIDI archive contains 456 files. Keyer exposes the 441 studies that have a matching release MIDI, source chord annotations, and a reader-compatible time base; the remaining files are retained here but are not presented as accompaniment-backed chart studies.
