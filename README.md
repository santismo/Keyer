# Keyer

Live app: https://santismo.github.io/Keyer/

Jazz Standards also has a roomier desktop layout at
https://santismo.github.io/Keyer/standards-desktop.html.

Choose the **Parkerize** bank in either Standards layout to generate an
original bebop solo over any catalog chart or create a new corpus-informed
bebop composition. Chart and solo complexity are independent, and each take
can be exported as a Format-1 MIDI file with chord markers.
