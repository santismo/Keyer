# Keyer

Live app: https://santismo.github.io/Keyer/

Songs (including the built-in jazz standards and local MIDI import) also has a roomier desktop layout at
https://santismo.github.io/Keyer/standards-desktop.html.

Choose the **Parkerize** bank in either Songs layout to generate an
original bebop solo over any catalog chart or create a new corpus-informed
bebop composition. Chart and solo complexity are independent, and each take
can be exported as a Format-1 MIDI file with chord markers. The performance
model is built from aggregate phrase, rhythm, contour, interval, swing, and
articulation statistics across all 50 Parker transcriptions; it does not copy
or store any source melody.
