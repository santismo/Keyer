How the two layouts differ

Chromatic: adjacent sectors move by one half step, so the interval labels appear in numerical order.

Fifths: adjacent sectors move by perfect fifths. The interval labels therefore jump around, but each label still correctly describes that outer note relative to the selected tonic.
